# Elite Cars — авто из Кореи в Россию через Кыргызстан

Информационно-продающий сайт для российской аудитории: подбор, выкуп и доставка автомобилей из Южной Кореи в Россию через Кыргызстан (ЕАЭС).

Стек: **Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Vercel Blob**. Публичные страницы статически пререндерятся и обновляются по требованию после правок в админ-панели.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполните переменные
npm run dev                  # http://localhost:3000
```

Продакшен: `npm run build && npm start`. Проект деплоится на Vercel, Netlify, любой Node-хостинг или в Docker без дополнительной настройки.

## Что нужно заменить перед публикацией

Все бренд-данные собраны в одном файле — `lib/site.ts`:

| Поле | Что указать |
| --- | --- |
| `name`, `legalName`, `tagline` | Название компании |
| `url` | Домен сайта (или переменная `NEXT_PUBLIC_SITE_URL`) |
| `contacts.*` | Телефон, WhatsApp, Telegram, email, адрес, часы работы |
| `social.*` | Ссылки на канал/соцсети |
| `stats` | Цифры для главной страницы (кол-во авто, сроки, экономия) |

Логотип — `components/Logo.tsx` и `app/icon.svg`.

## Админ-панель — `/super/secret/admin`

Вход по логину и паролю из переменных окружения `ADMIN_LOGIN` / `ADMIN_PASSWORD` (пароль ≥ 8 символов). Сессия — подписанная HttpOnly-cookie на 7 дней; смена пароля разлогинивает всех. Раздел закрыт от индексации и защищён в `proxy.ts`, а каждое действие дополнительно проверяет сессию на сервере.

| Раздел | Что можно делать |
| --- | --- |
| **Автомобили** | Добавлять, редактировать, скрывать, удалять и менять порядок моделей. Фото загружается в Vercel Blob. Каждая модель — SEO-страница `/avtomobili/[slug]` |
| **Галерея** | Альбомы (один альбом = одна реальная сделка), массовая загрузка фото, тип («Автомобиль» / «Осмотр»), подписи, порядок |
| **Видео** | Ссылки YouTube под этапами на странице «Как это работает» (watch / youtu.be / shorts). Сами видео остаются на YouTube |
| **Заявки (CRM)** | Все отправленные формы: контакт, авто, комментарий, страница, статус (новая / в работе / закрыта / спам), заметки менеджера |

После любого сохранения публичные страницы перегенерируются автоматически (`updateTag` + `revalidatePath`).

## Хранилище — Vercel Blob

Всё редактируемое хранится в одном **публичном** Blob-сторе:

| Путь в сторе | Содержимое |
| --- | --- |
| `cars/…`, `gallery/<album>/…` | Фото (неизменяемые файлы со случайным суффиксом, кэш CDN — 1 год) |
| `data/cars/`, `data/gallery/`, `data/videos/`, `data/leads-state/` | JSON-документы. Каждое сохранение создаёт новый файл и удаляет старые — так обход кэша CDN не нужен |
| `leads/<id>.json` | По одному файлу на заявку (append-only, конфликтов при одновременной отправке нет) |

Настройка: Vercel → Storage → Create → **Blob** → access **Public** → Connect to project, при подключении включите *Add a read-write token env var* (`BLOB_READ_WRITE_TOKEN` нужен для загрузки фото прямо из браузера). Для локальной разработки скопируйте токен в `.env.local`.

Пока токена нет, приложение работает в **локальном режиме**: данные и файлы пишутся в `public/uploads/` (в git не попадает). Это удобно для разработки, но не для продакшена.

### Перенос существующих фото в Blob

Исходные фото лежат в `public/cars` и `public/gallery` и используются как стартовый контент. Чтобы перенести их в Blob (и зафиксировать текущий каталог/галерею/видео в хранилище):

```bash
npm run migrate:blob             # загрузка + обновление документов
npm run migrate:blob -- --remove # ...и удаление локальных копий из public/
```

Скрипт идемпотентен — переносит только картинки, которые ещё ссылаются на `/cars/…` или `/gallery/…`.

## Заявки

Форма (`components/LeadForm.tsx`) отправляет данные в `POST /api/lead`. Заявка сохраняется в CRM (Vercel Blob) и, если заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, дублируется сообщением в Telegram со ссылкой на CRM. Есть honeypot-поле и простой rate-limit.

Кнопки WhatsApp/Telegram открывают чат с предзаполненным текстом.

## SEO

- `metadata` на каждой странице: title, description, canonical, Open Graph, Twitter, keywords.
- Динамические OG-изображения (`opengraph-image.tsx`) для главной, моделей и статей — с кириллическими шрифтами из `assets/`.
- Структурированные данные JSON-LD: `Organization`, `WebSite`, `Service`, `HowTo`, `FAQPage`, `BreadcrumbList`, `Product` (модели), `Article` (блог).
- `app/sitemap.ts`, `app/robots.ts`, `app/manifest.ts`.
- Семантическая разметка, `lang="ru"`, `<h1>` на каждой странице, хлебные крошки.
- Яндекс.Метрика и верификация Яндекс/Google Webmaster — через переменные окружения.
